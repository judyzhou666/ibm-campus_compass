# Technology stack

Use Rust for backend services and API endpoints, including the future IBM watsonx integration. Do not implement backend application code in Python. Use TypeScript or JavaScript for frontend application code.

# Documentation

Place all new project documentation in `docs/`, except source pages intended for the GitHub Wiki, which belong in `wiki/`. Edit existing documents in place unless the user asks to reorganize them. Keep agent instruction entrypoints such as this file at their tool-required paths.

When adding or changing Wiki publishing, read `docs/github-wiki.md` for the source layout, credential requirements, and validation commands.
