# Bob task session reports

The AI Experiential Learning Lab requires **each team member** to export every Bob IDE task related to Campus Compass and add it here for judging. This folder holds only real exports from Bob IDE. Do not write, edit, or recreate reports by hand.

## How to export (from the lab guide)

1. In Bob IDE's chat, open **Views and More Actions → History**.
2. Confirm the workspace is this repository (choose **All** if your tasks span several workspaces).
3. Open a task related to the project and select its **task header** to show the consumption summary.
4. Take a **screenshot** of the consumption summary.
5. Select **Export task history** to download the task as Markdown.
6. Repeat for every project-related task.

## Before adding files

- Check every export and screenshot for API keys, IAM tokens, project IDs you do not want public, and other credentials. Remove them before committing; the IBM Security team deactivates accounts whose credentials appear in a repository.
- Make sure Bob is on the provisioned team **ibm-skillsbuild-ell** (Settings → General) so usage is not charged to a personal account.

## Naming

Put each person's files in their own folder so authorship is clear:

```
bob_sessions/
  Judy/
    2026-11-10-init-project-context.md
    2026-11-10-init-project-context.png
  Doris/
  Bella/
  Tingting/
```

Use `YYYY-MM-DD-short-task-name` for both the Markdown export and its screenshot.
