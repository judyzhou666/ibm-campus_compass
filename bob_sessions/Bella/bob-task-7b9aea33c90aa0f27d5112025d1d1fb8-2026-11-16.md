#### 5. Minor: `ed-mobile-bar` is rendered in the DOM at all viewport widths, but `display: none` on desktop

The bar is in the DOM always. This means its button — which duplicates the RSVP card button — can technically be reached by AT on desktop if a screen reader ignores `display: none`. The correct pattern would be `aria-hidden="true"` when not displayed. Since the spec's mobile bar has `display: none` at >700px:

```tsx
{/* Mobile fixed bottom bar */}
<div className="ed-mobile-bar" aria-hidden="true">
```
…and flip it in the CSS using a media query or a JS state variable. The simplest correct fix is adding `aria-hidden` to the element — but since it's `display: none` and most AT respects that, this is low severity.
