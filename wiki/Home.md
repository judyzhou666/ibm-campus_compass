# Campus Compass

Campus Compass helps students discover campus opportunities and build a weekly plan around their interests and availability.

This is our IBM AI Experiential Learning Lab demonstration. Events and student schedules are fictional. Chat is currently simulated; IBM watsonx integration is a later step.

## Editing this Wiki

Edit the Markdown pages in the repository's `wiki/` folder and open a pull request into `main`. After merging, the **Publish GitHub Wiki** workflow updates these pages once the publishing credential is configured.

General project documentation and setup notes belong in `doc/`. Wiki page sources are the explicit exception and belong in `wiki/`.
