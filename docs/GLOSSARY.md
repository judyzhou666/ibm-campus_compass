# Campus Compass

Campus Compass helps students choose fictional campus events for a demonstration week.

## Language

**Demo enrollment**:
A student's approved addition of an eligible event to their demo calendar, including a confirmed demo RSVP when required. It reserves no real seat and contacts no organizer.
_Avoid_: Booking, real registration

**Planning conversation**:
A student's sequence of requests and event suggestions, including follow-up filters and cancellation replacements. Suggestions become calendar choices only through student approval.

**Draft plan**:
The current set of suggested events awaiting student approval. It is separate from the student's chosen calendar events.
_Avoid_: Confirmed schedule

**Busy commitment**:
A class or personal commitment that makes part of the demo week unavailable, including the selected travel buffer when checking event conflicts.
